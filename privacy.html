Keine Datenerhebung

Die App Druck einfach! erhebt, speichert oder verarbeitet keine personenbezogenen Daten. Es werden keine Analyse-, Tracking- oder Werbedienste verwendet.

Netzwerkkommunikation

Die App kommuniziert ausschliesslich mit Druckern in Ihrem lokalen WLAN-Netzwerk, um Druckauftraege zu senden. Dabei werden keine Daten an externe Server oder Dritte uebermittelt.

Webseiten-Druck

Beim Drucken von Webseiten wird die angegebene URL direkt auf Ihrem Geraet geladen und verarbeitet. Der Inhalt wird nicht an Dritte weitergeleitet.

Berechtigungen

  • Internet / WLAN: Fuer die Kommunikation mit Netzwerkdruckern und das Laden von Webseiten
  • Benachrichtigungen: Fuer den Status von Druckauftraegen

Datenspeicherung

Druckdateien werden temporaer im App-internen Cache gespeichert und automatisch geloescht. Es findet kein Cloud-Upload statt.

Privacy Policy

Last updated: April 12, 2026

No Data Collection

Just Print! does not collect, store, or process any personal data. No analytics, tracking, or advertising services are used.

Network Communication

The app communicates exclusively with printers on your local Wi-Fi network to send print jobs. No data is transmitted to external servers or third parties.

Web Page Printing

When printing web pages, the specified URL is loaded and processed directly on your device. The content is not forwarded to third parties.

Permissions

  • Internet / Wi-Fi: For communication with network printers and loading web pages
  • Notifications: For print job status updates

Data Storage

Print files are temporarily stored in the app's internal cache and automatically deleted. No cloud upload takes place.
